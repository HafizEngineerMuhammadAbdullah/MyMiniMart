## ⚙️ How It Works

- Click moon icon 🌙
- `body.classList.toggle("active")`
- CSS switches background + text color
- JS replaces icon class dynamically:
  - Moon → Sun ☀️ (light mode)
  - Sun → Moon 🌙 (dark mode)
